# ELI-1541 — Excluding low-quality evidence hosts

Public research edition of the historical report. Dataset rows, internal review material and private artifacts are omitted. Commands describe the historical experiment; see ../reproduction.md for the supported standalone setup.

Three hosts produced more than eleven false relations in one historical run. Failure types included invented sample names, inferred usage marketed as data, and a job advertisement treated as relationship evidence. The hosts were added to `EXCLUDED_HOSTS`.

The report records no controlled before/after measurement, exact final count or repeated-run estimate. This is a targeted source-quality intervention, not evidence of a general precision gain. Named source examples and compiled relationship rows are omitted.
